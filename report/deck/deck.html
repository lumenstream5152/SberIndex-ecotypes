Сходимость · Лаг-лидерствоЛИСТ 11 / 12
Вся Россия сходится в один клуб по маркетплейсам — и остаётся тремя типами
Клубы сходимости Phillips–Sul (свой порт log-t, HAC): маркетплейсы+продовольствие — один глобальный клуб по всем 3 критериям (log-t t=+0,18 > −1,65; σ t=−12,5; β t=−43,2). Клубы ортогональны типам (ARI ≤ 0,06): сходимость идёт внутри типов, не стирая их.
Лаг-лидерство: 4 437 направленных рёбер из 2 031 120 пар (phase-randomization суррогаты, BH-FDR 5%, cutoff r=0,834 против нулевого q99=0,680).
Топ-«маяки» — периферия: средняя исходящая степень типа 0 = 2,52 против 0,31 у метрополисов.
Рёбра лидерства не локальнее случая (1,3% против 2,5% в пределах 150 км) — лидерство не про соседство.
Глубже всех в поле — не «уникально»: у одного конкурента есть зачаточный lead-lag по типам; признаём это в отчёте.
